# 🎮 Tic Tac Toe - Flutter

A modern and responsive **Tic Tac Toe** game built with **Flutter**. This project demonstrates Flutter UI development, state management, game logic, and responsive design while providing a smooth gaming experience on Android, iOS, and other Flutter-supported platforms.

---

## 📱 Features

- 🎲 Two-player Tic Tac Toe gameplay
- 🎨 Clean and modern user interface
- ⚡ Fast and responsive performance
- 🔄 Restart game functionality
- 🏆 Winner detection
- 🤝 Draw detection
- 📱 Cross-platform support (Android, iOS, Web, Windows, macOS, Linux)
- 💙 Built entirely with Flutter

## 🎮 How to Play

1. Player X starts the game.
2. Players take turns placing their marks.
3. The first player to align three marks horizontally, vertically, or diagonally wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Press **Restart** to play again.
